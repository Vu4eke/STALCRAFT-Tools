- 🧩 Централизованный хаб скриптов в стиле Hanslo
- ⚡ Быстрый и удобный запуск через лоадер
- 🔒 Система авторизации для безопасности

```bash
1. Скачайте лоадер из последнего релиза
2. Запустите программу
```
